When adding an image to HTML, always provide meaningful alternative text:

<img
  src="images/tomatoes.jpg"
  alt="Rows of ripe red tomatoes growing in the Campus Farm hoop house"
>

If an image is purely decorative, use an empty alt attribute:

<img src="images/decorative-leaves.png" alt="">
